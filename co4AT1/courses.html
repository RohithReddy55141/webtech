CO4 AT1 - Question 1: Interpret the XML Structure

XML Source Dataset (`courses.xml`)

<?xml version="1.0" encoding="UTF-8"?> <courses> <course id="C101"> <code>WEB301</code> <name>Web Technology</name> <faculty>Dr. A. Sharma</faculty> <students>45</students> <credits>4</credits> <type>Theory</type> </course> <!-- Additional <course> entries C102 to C105 --> </courses>

Q1 Questions & Solutions

a. Identify the root element:
The root element of the XML document is <courses>.
The root element is the single top-level parent container encapsulating all child elements in the document.
b. Identify the repeating record element:
The repeating record element is <course> (with attributes like id="C101").
Each course entity is represented by an individual <course> element node repeated under <courses>.
c. Identify the attribute used to uniquely identify each course:
The attribute used to uniquely identify each course is id (e.g., id="C101", id="C102", etc.).
Attributes reside within the opening tag of an element. Here, id acts as the primary identifier key for each course record.
d. Identify the elements that represent numeric information:
The elements representing numeric information are:
<students> <credits>
<students> contains integer values (e.g., 72, 64, 50, 45, 36) and <credits> holds credit counts (e.g., 4, 3, 2).
e. State whether the XML document is structurally well-formed and justify your answer:
Yes, the XML document is structurally well-formed.

✓ Single Root Element

All nodes are contained within a single outer <courses> element.

✓ Matching Tags

Every opening tag has a strictly matching closing tag (e.g., <course>...</course>).

✓ Clean Nesting

Child elements are cleanly nested without overlapping parent/sibling boundaries.

✓ Quoted Attributes

All attribute values (such as id="C101") are enclosed in double quotes.
